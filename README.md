# AITranslationsPlatformPoc

Cloud-native proof of concept for managing assets, generating multilingual
translations, and producing localized PDF reports.

## Architecture

- `FrontendApp/`: Angular interface localized in English, French, and German.
- `AssetManagementService/`: FastAPI CRUD API, database migrations, and PDF report generation.
- `TranslationService/`: FastAPI service and scripts for Azure Translator, XLIFF/JSON validation, and versioned publication to Cloudflare R2.
- `.github/workflows/`: CI/CD pipelines for tests, container validation, translation publication, and frontend deployment.

The frontend calls the Asset Management API deployed on Render. Translation
artifacts are generated by TranslationService, stored as immutable versions in
Cloudflare R2, and consumed by the frontend and Asset Management Service.

## Local development

### Asset Management Service

```powershell
cd AssetManagementService
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements-dev.txt
python -m pytest -q
python -m uvicorn app.main:app --reload
```

### Translation Service

```powershell
cd TranslationService
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -e ".[dev]"
python -m pytest -q
python -m uvicorn app.main:app --reload
```

### Frontend

```powershell
cd FrontendApp
npm ci
npm test -- --watch=false
npm run build:localized
npm start
```

## CI/CD branches

CI runs for `main`, `develop`, `develop-stage`, and feature branches where
configured. Pull requests into `main`, `develop`, or `develop-stage` run the
corresponding service checks. Successful frontend CI runs from the integration
branches can deploy the validated build to Cloudflare Pages.

Secrets and cloud credentials must be configured as GitHub Actions secrets or
variables and must not be committed to the repository.
